## Decisions that differ from the build prompt

| What                                   | Prompt said                                  | Built                                                                                  | Why                                                                                                    |
| -------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `--text-3` token                       | `#5f606a`                                    | `#85868f`                                                                              | 12px labels in that colour fail 4.5:1 contrast; Lighthouse accessibility dropped to 96.                |
| Font preloads                          | Preload fonts                                | Only Bebas Neue (wordmark) is preloaded                                                | Inter and JetBrains Mono have metric-matched fallbacks (no shift); preloading all three slowed first paint. |
| Rendering                              | Static SPA                                   | Static SPA, prerendered to HTML at build and hydrated                                  | Copy is in the DOM without JS (spec §10) and the largest paint no longer waits for the bundle.        |
| MotionPathPlugin for packets           | GSAP MotionPathPlugin                        | Path followed via `getPointAtLength` in a plain tween                                  | Same visual, 8 kB gzipped less JS.                                                                     |
| Code highlighting                      | shiki at build or pre-highlighted strings    | Pre-highlighted HTML strings in `data/work.ts` with 7 token classes                    | Zero runtime cost; snippets are short.                                                                 |
| `now.txt` verify flags                 | —                                            | `# verify` shown inline on the two VERIFY rows                                          | Visible reminder until the facts are confirmed. Remove `verify: true` in `About.tsx` rows when done.   |
| Missing-image detection                | `onError` swap at runtime                    | Build-time manifest of `public/img` (`virtual:image-manifest`)                          | No request, no console 404, no placeholder flash; same answer on server and client. Dev reloads on add. |
| App chunk preload                      | —                                            | Not preloaded; loaded one frame after first paint                                       | Preloading it made Lighthouse chain first paint to the bundle (92 → 98–99 mobile perf locally).        |
